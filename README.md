# Poisson hash-DAG challenge · public test

This repository rehearses submission checking and byte scoring with synthetic entries. The research target is symbolic DAG covering with shared Poisson(1) histories. The public test has no cash prizes.

The organizer's verified lower bound is 99 bytes. The proposed 756-byte GRS-CC construction still needs a complete certificate. The model and proof sources are under `formal/PoissonDAG`.
